# Marquesas Fish ID (built app)

Offline-capable fish-ID study cards for freedive spearfishing in the Marquesas Islands, French Polynesia.

This repository only holds the built web app served by GitHub Pages. Open the site in Safari on an iPhone, tap Share → Add to Home Screen, then open it from the Home Screen once while online; it works offline after that.

Photos come from Wikimedia Commons and iNaturalist under their Creative Commons licences (some non-commercial); each photo's author and licence are shown in the app and on its Credits page.
